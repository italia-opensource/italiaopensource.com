How contributing works

  1. Edit the awesome list

    Fork awesome-italia-opensource and add your entry — just a name and a short description in a JSON file.

  2. Open a pull request

    Submit your change as a pull request. Read the contributing guidelines first so it sails through review.

  3. Reviewed & published

    Once approved, your project or community appears on italiaopensource.com automatically.
